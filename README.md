# Oasis Beauty Center

Aplicación web para reservas de tratamientos de estética.

## Estado actual
Primera versión visual disponible en `index.html`: portada blanco y dorado, información de servicios y formulario para preparar una consulta de turno. Todavía no almacena reservas, envía mensajes ni procesa pagos.

2. Configurar Firebase Authentication y Firestore con permisos para administración y soporte.
3. Implementar calendario con bloqueo de turnos en tiempo real.
4. Integrar Mercado Pago mediante backend seguro y validar notificaciones de pago antes de confirmar una reserva.
